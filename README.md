One funny sign for the door of a haunted server room, 120 characters at most.

## The sign

> DO NOT EXORCISE THE GHOST IN RACK 7 — he's the only one who still knows the root password.

## How it works

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt`. The joke lands in one line from the collision of
office IT life and the supernatural: the ghost is not the problem, he
is the only one who remembers the root password — so exorcising him
would lock everyone out.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
